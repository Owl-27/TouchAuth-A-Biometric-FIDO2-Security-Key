# TouchAuth Project Documentation

This directory contains the technical documentation for the TouchAuth Biometric FIDO2 Security Key.

## Documents

- `TouchAuth-Project-Report.pdf` – Detailed project report.
- `System-Architecture.png` – Overview of the system components and communication flow.
- `Circuit-Diagram.png` – Hardware connections between the ESP8266, R307 fingerprint sensor, and Raspberry Pi Pico.

## Project Overview

TouchAuth integrates fingerprint verification with a USB-based authentication device. The ESP8266 manages fingerprint-related operations, while the Raspberry Pi Pico provides the USB device interface.

## Purpose

This documentation explains the hardware design, system architecture, implementation, testing, and future improvements of the project.

*Only documents that have actually been added to this directory should be considered available.*
